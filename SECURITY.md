# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting (Security tab → "Report a vulnerability") or email **tech@apricotstays.in**.

We aim to acknowledge within 3 working days and to fix confirmed issues affecting guests' data as a priority.

## Scope

- `apricotstays.in` and `www.apricotstays.in`
- This repository

`staiz.apricotstays.in` is a separate product; report issues there the same way and we will route them.

## Our practices

- 2FA is required for every member of the `apricotstays` GitHub organisation.
- `main` changes only through pull requests reviewed by the owner.
- No secrets in this repository. Credentials live in Cloudflare/GitHub encrypted settings.
- The site currently collects **no personal data**. If forms are added, they will carry a consent notice aligned with India's DPDP Act, 2023.
- Dependencies are updated monthly via Dependabot.
